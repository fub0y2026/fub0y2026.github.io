Filter过滤器审计

总结：

1、 doFilter：从session中提取user 参数的值，如果不为null，则跳过认证，这里是没有问题的

2、如果访问的url 中包含 /doc.html、/register.html、/login.html，这些字符串，则不进行认证，直接放行，这样其实是不严格的，如果url 长这样呢：/doc.html/../home.html，就可能会出现未授权访问

3、访问.css、.js、.jpg、.png、.gif、.ico、/user/login、/user/registerUser、/v2/api-docs这些内容的时候也不需要认证。同样不严格，如：.css/../home.html，同样存在未授权

4、最后如果用户没有权限，则跳转到登录页

例如

这里我们没有登录，但访问到了静态文件

直接添加 Filter

这是一个 Servlet Filter，会拦截所有进入的 HTTP 请求。

在进入目标 Servlet/Controller 之前，把请求对象（HttpServletRequest）用一个 包装类（Wrapper） 包起来。

这个包装类会在调用 getParameter、getParameterValues、getHeader 时，对返回值做 XSS 清理。

如果某些 URL 需要排除（不过滤），可以配置在 urlExclusion 列表中。
