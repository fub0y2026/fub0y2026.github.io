    JAVA序列化和反序列化

    Java 序列化就是将 java 对象转换成字节序列（二进制，写文件）的过程；

    java 反序列化是指将字节序列（通过读文件的方式）恢复为 Java 对象的过程；

    serializable (序列化接口) 接口：

    被序列化对象必须添加 Serializable 这个接口，才能序列化为字节。这个用来表示这个类可以被 ObjectOutputStream 序列化，以及被 ObjectlnputStream 反序列化

    问题

    其实这里看着简单，但仔细调试会发现，这个dns解析是发生在序列化的时候，而不是反序列化

    原因：

    1. 序列化时：
      • HashMap 在序列化时会调用 key.hashCode()（即 URL.hashCode()）。
      • 由于 hashCode 初始为 -1，会触发 DNS 查询，并缓存计算结果。
    2. 反序列化时：
      • HashMap 在反序列化时 也会调用 key.hashCode()。
      • 但由于 hashCode 已经被计算过（不再是 -1），直接返回缓存值，不再触发 DNS 查询。

    结果

    如果不修改hashCode的值，那么我们传入的url就会触发DNS请求，并被hash编码，此后并不能触发反序列化。

    解决

    如果能修改hashCode的值，那么就可以绕过put时hash的触发，而在put之后再把hashCode改回来，就完成整条链子了。

    我们可以通过反射，修改对象属性的值。

    最后的链子就是：
