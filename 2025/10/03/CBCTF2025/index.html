ezxss（xss+js代码编写）

  1. POST /submitNote
    保存 noteName 和 note 到内存对象 notes 中。
  2. GET /notes/:noteName
    返回 notes[noteName] 的内容，直接作为 HTML 发送（Content-Type: text/html），这里存在 XSS 漏洞，因为用户输入的内容没有经过转义。
  3. GET /flag
    只允许本地 IP（127.0.0.1 或 ::1）访问，返回 /flag 文件内容。
  4. GET /bot
    接受 noteName 参数，用 Puppeteer 打开 http://127.0.0.1:3000/notes/ + 该 noteName 的页面，即模拟管理员（有本地访问权限）访问该笔记。

一开始我的解题思路是写个恶意js代码让bot访问然后把flag外带到VPS上，但后面尝试了不行，看了一下题目介绍发现该题不出网

有点迷了，后面经过ai提示，发现可以让bot把/flag写到我们可访问的位置（也就是notes中）

内存马查杀

已知flag在/check.log文件中，需要清除内存马后才能回显flag

因为项目是用Tomcat启动的，所以先看看Tomcat日志文件是怎么检测内存马是否被查杀的 -> /usr/local/tomcat/logs/localhost_access_log.2025-09-27.txt

杀内存马最简单的方式就是重启Web服务器，关机和启动脚本位于/usr/local/tomcat/bin/shutdown.sh和/usr/local/tomcat/bin/startup.sh

不能逐个执行，若先关机我们的马就掉了，重新写一个restart.sh，先执行shutdown.sh再执行startup.sh

给权限 -> chmod +x /usr/local/tomcat/bin/restart.sh

执行restart.sh，重启后再读/check.log，拿到flag
