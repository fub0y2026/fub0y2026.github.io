JsonPickle

jsonpickle 是一个把任意 Python 对象图序列化为 JSON、并能从该 JSON 恢复出原始对象的库。

为了能“还原对象”，它在 JSON 中存储额外的元信息（例如 py/object, py/state 等），以记录对象的模块/类与状态，从而在反序列化时重新 import 并构造对象。由于它要恢复任意类的实例，反序列化过程会涉及运行对象的构造/恢复逻辑，这就是危险的根源

py/repr

jsonpickle默认开启safe，_restore_repr_safe是调的_loadmodule，实际上也不能利用这个标签

py/repr 用于序列化那些可以通过 repr() 函数准确表示，并且可以通过 eval() 函数重建的对象。它本质上是一种"代码序列化"方式。

基本思想：将对象的 repr() 输出序列化，反序列化时通过 eval() 重建对象。

py/repr 的核心机制就是 eval()，这本身就意味着任意代码执行：

导入/左边的模块作为locals，/右边的作为eval的内容

py/reduce

py/reduce 实现了 Python 的 Pickle 协议，它允许对象自定义自己的序列化和反序列化行为。通过 __reduce__ 或 __reduce_ex__ 方法，对象可以完全控制如何被重建。

核心思想：对象告诉反序列化器：“调用这个可调用对象，传入这些参数，就能重建我”。

__reduce__返回一个元组用于恢复对象，这个元组的长度可为2~5，后三个元素为可选。

第一个元素为可调用的对象，用于重建对象时调用；第二个元素为参数元组，用于传入可调用对象。

py/object

py/object 是 jsonpickle 用于序列化自定义类实例的主要标签。它的作用是告诉反序列化器：“这个JSON数据原本是一个Python对象，需要重建为指定类的实例”。

核心功能：将JSON数据转换回特定类的对象实例。

注意：方法不会被序列化，只有实例属性会被保存。
