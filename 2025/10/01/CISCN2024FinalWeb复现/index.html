ezJS（简单）

**考点：**express引擎解析的一个trick，在高版本的express已经修复

break

看附件源码：

主要有三个接口：

文件上传接口/upload：禁止上传 .ejs 文件

文件渲染接口/render：使用 EJS 渲染文件，禁止渲染.ejs文件

文件重命名接口/rename：校验 newPath，不允许是 app.js、带 \ 或 .ejs，校验 oldPath，禁止 .. 目录穿越和 flag，不允许改名 为 .ejs 文件

​

这里我尝试测了一下功能：
上传了111.png

然后/render?filename=111.png:

ai的解释是：

Express 在调用 res.render(filePath) 的时候，把 111.png 当成了一个 EJS 模板文件 来渲染。

  • res.render() 方法本来就是用来渲染 模板引擎文件（比如 .ejs），它会去找对应的 “视图引擎”。
  • 你传了 111.png，Express 以为要用 "png" 这个“模板引擎”去渲染，于是尝试 require('png')，结果报错：找不到 png 模块

重点也是考点：

深入源码：

this.ext是我们传入的最后一个后缀，去掉.传给了mod，然后被require，require默认是读取node_modules中的index.js，假设这里mod是js，那么就会require node_modules/js/index.js

解题思路：
这里我们尝试上传一个index.js，然后通过重命名文件 index.js->../node_modules/xxx/index.js，这样我们自己构造的index.js就来到/node_modules/xxx下了，再通过渲染/render?filename=xxx.js

这样会require(node_modules/xxx/index.js),从而触发我们写的恶意代码

由于这里我是本地复现，没有flag,直接弹个计算器：

index.js:

渲染：/render?filename=1.fuboy

fix

直接把.js加入黑名单即可

解题

既然ssti那里不能直接rce，那尝试逃逸获取key字典：

因为沙盒的存在，所以模板的渲染都是基于沙盒环境实现的，而在进行模板渲染的函数safer_render_template里面可以发现一个传参规则**kwargs

kwagrs代表的就是模板渲染时传参的变量，这个变量数组里面的变量是在沙盒环境里可以使用的

Fobee（困难）

**考点：**beetl模板注入+md5逐字符猜解盲注

引自CISCN2024-Final-AWDP-Fobee - EddieMurphy’s blog

看源码：

根路由：username 参数不为空，username是否等于admin，是->小写后不能等于 admin,满足条件就返回一个带有 =====随机密码===== 的页面，否则返回 "hello"

**/render:**参数：

  • pass：传入的口令，必须等于启动时生成的 password 才能继续。
  • tp：一个经过 Base64 编码的模板字符串,解码 tp → 得到模板字符串

将渲染结果取 MD5 摘要，放入返回页面的 msg

**/env:**直接返回当前运行的 Java 版本

**generateRandomString()😗*用 Random 从 CHARACTERS 里随机取字符，拼接成指定长度的字符串。用于生成 password。

**getMD5Hash()😗*对输入字符串计算 MD5 哈希，返回小写 16 进制形式
