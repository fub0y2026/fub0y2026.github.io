[入口靶机]pingline

考点:spawn 命令的Prototype Pollution to RCE 分析

前置知识

新版JS Prototype Pollution to RCE学习解析-先知社区

spawn 的工作方式

这里的 spawn 函数是 参数化执行，而不是 字符串拼接执行。这意味着：

  • 第一个参数：要执行的命令 "ping"
  • 第二个参数：参数数组 ["-c4", "127.0.0.1;ls", "-W1"]

实际执行的命令：

  1. JSON 解析后：body.ip = "127.0.0.1;ls"
  2. spawn 调用：spawn("ping", ["-c4", "127.0.0.1;ls", "-W1"])
  3. 实际执行的命令：系统看到的是：
    • 命令：ping
    • 参数1：-c4
    • 参数2：127.0.0.1;ls （作为一个整体字符串）
    • 参数3：-W1

绕过方法

在 Unix shell 中，分号 ; 是命令分隔符，但前提是命令是通过 shell 执行的。

spawn 默认是不通过 shell 执行的，它直接调用可执行文件并传递参数数组。

可以通过以下两种方式令spawn将其执行：

  1. 通过 shell 执行：使用 {shell: true} 选项
  2. 或者使用 exec：exec 函数默认通过 shell 执行
