前置知识

参考CVE-2014-3529，Apache POI XML外部实体注入漏洞，poi-ooxml-3.10-FINAL.jar及以下版本会有影响！

在 Apache POI 3.10.1 之前 的版本中，由于 OPC SAX 解析器 在处理 OpenXML 文件（如 .xlsx、.docx）时，未正确禁用 XML 外部实体（XXE, XML External Entity） 解析，导致攻击者可以构造恶意的 Office 文件，读取服务器上的任意文件（如 /etc/passwd、数据库配置文件等）。

OPC 是微软定义的一种文件容器标准，用于存储 OpenXML 格式的文档（如 .xlsx、.docx）。

OpenXML 文件本质是一个 ZIP 压缩包，内部包含多个 XML 文件（如 xl/workbook.xml、word/document.xml）和资源文件。

SAX是一种基于事件驱动的 XML 解析方式（对比 DOM 解析，SAX 更节省内存）
