QLwist(SSRF打graphql+JWT算法混淆+vm沙箱逃逸)

题目分析

路径 作用
/auth/register 注册普通用户
/auth/login 登录，返回 JWT token
/dashboard、/profile 普通登录用户页面
/admin 需要 admin 或 super_admin
/admin/super 需要 super_admin
/admin/super/evaluate super_admin 才能调用的 JS 表达式执行器
/api/link-check 登录用户可以让服务器去访问一个 URL
/graphql GraphQL API，但限制只能本机访问

Express 中间件配置

认证中间件

  • 从 Authorization header（Bearer token）或 Cookie 中提取 JWT
  • 验证 token 后将用户信息挂载到 req.user

角色权限控制

  • 高阶函数，返回中间件，检查用户角色是否在白名单中
  • 支持多角色：如 requireRole('admin', 'super_admin')

最重要的：GraphQL API 安全配置

  • GraphQL 端点仅允许本地访问（127.0.0.1）
  • 禁用内省查询防止泄露 schema
  • 禁用批量请求避免攻击

注册：

  • 不允许注册 admin 用户名
  • 新用户默认为 user 角色
