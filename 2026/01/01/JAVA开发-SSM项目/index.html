总结

这算是一个简答且落后的SSM实现了，但对目前的我来说差不多了

总结一下整合关系：

Spring + MyBatis：通过 application-dao.xml + application-service.xml 实现：

  • DataSource → SqlSessionFactory → Mapper → Service 注入

Spring MVC + Spring：

  • web.xml 启动 DispatcherServlet → 加载 spring-mvc.xml → 扫描 Controller
  • Controller 自动注入 Service

Spring MVC 管理 Web 层，Spring 管理业务层，MyBatis 管理数据层，三者通过 Spring 容器整合在一起，实现 SSM 架构。
