SUDO提权-rsync

看看sudo -l

rsync命令可以免密码以root用户权限运行，rsync命令可以理解成一个加强版的cp命令，既然可以使用root权限运行，那么就可以把/root/下的所有文件拷贝到/tmp目录下查看。

成功取得第三个flag

或者可以直接提到root权限：

  • sudo /usr/bin/rsync: 以 root 权限运行 rsync
  • -e 'sh -c "sh 0<&2 1>&2"':
    • -e 选项指定远程 shell 程序
    • 这里指定了一个 shell 命令，它会创建一个新的 shell
    • 0<&2 和 1>&2 是文件描述符重定向，将标准输入和输出重定向到标准错误
  • 127.0.0.1:/dev/null: 连接到本地主机的 null 设备（这是一个虚拟目标）

但读flag都提示pivoting backwards
