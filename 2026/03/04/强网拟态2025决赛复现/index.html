内网10052端口存在zabbix java gateway, 打 Zabbix Java Gateway RCE

Zabbix 是一个企业级的开源监控解决方案，广泛用于监控网络、服务器及其他设备的性能。Zabbix Java Gateway 是 Zabbix 组件之一，负责监控 Java 应用的性能，它通过 JMX 协议与 Java 应用进行通信。

CVE-2021-25275 漏洞发生在 Zabbix Java Gateway 中，攻击者可以通过构造特定的请求，利用反序列化漏洞触发远程代码执行（RCE）。这个漏洞存在于 Zabbix Java Gateway 对 JMX 服务的错误处理方式中。

漏洞利用流程

  1. 攻击者构造恶意请求：
    攻击者构造恶意的 JMX 请求，发送到 Zabbix Java Gateway 的接口。该请求会通过特定的反序列化对象进入 Zabbix 的 Java Gateway 代码中。
  2. 反序列化漏洞触发：
    Zabbix Java Gateway 在接收到该恶意数据后，会进行对象反序列化，处理过程中未对反序列化数据进行有效的安全检查，导致恶意代码得以执行。
  3. 执行任意命令：
    攻击者可以通过精心构造的对象触发远程代码执行，从而在目标服务器上执行任意命令或恶意脚本。

elephant Datart 1.0.0-rc3漏洞分析(CVE-2024-12994)-先知社区

跟着文章进行复现

组件：Running-Elephant Datart
受影响版本：1.0.0-rc3

漏洞原理

Datart 在处理某个文件上传或接口参数时：

  • 接收客户端可控数据
  • 对该数据进行 ObjectInputStream.readObject()
  • 未做白名单限制
  • 未做类型校验
  • 未使用安全反序列化过滤器

这意味着：

攻击者可以构造恶意序列化对象 → 触发 gadget 链 → 执行任意代码

漏洞的描述中获取到3个要素，

  • 漏洞位置在extractModel
  • 漏洞类型是反序列化
  • 漏洞接口是/import
