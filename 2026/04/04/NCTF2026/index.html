Crypto

Ez_RSA(高低位逐位恢复p,q)

一个变种rsa

bin(q)：例 0b101100

bin(q)[:1:-1]：先去掉 "0b"，再从末尾开始逆序排列q的二进制，结果：001101（最高位变最低位，次高位变次低位）

int(... ,2)：int(翻转后的二进制 , 2),变回整数

hint = p ^ q_rev：将变化后的q和原始p进行异或

两个已知式:

rev(q) 表示 q 的 512 位二进制按位反转。

这里存在一个二进制高低位的关系：p 的低位和 q 的高位绑定在一起，q 的低位和 p 的高位绑定在一起。

设：

  • p_i 表示 p 的第 i 位（二进制，最低位是第 0 位）
  • q_i 表示 q 的第 i 位
  • h_i 表示 hint 的第 i 位

由于 rev(q) 的第 i 位其实是 q_{511-i}，所以：

即q_{511-i} = p_i ^ h_i，同理：p_{511-i} ^ q_i = h_{511-i}

逐位恢复p,q

乘法有一个重要性质：

  • 若知道 p、q 的低 k 位，就能检查 p*q 的低 k 位是否等于 n 的低 k 位。
  • 同时因为 hint 把低位和高位关联起来，所以每次枚举低位时，高位也会被一起确定。

于是可以做一个 按位 DFS / 回溯搜索：

每次处理一对位置：

  • 低位位置 i
  • 对应高位位置 j = 511 - i

枚举：

  • p_i ∈ {0,1}
  • q_i ∈ {0,1}

然后由 hint 推出：

  • q_j = h_i ^ p_i
  • p_j = h_j ^ q_i

这样每走一步，就同时确定了：

  • p 的第 i 位和第 j 位
  • q 的第 i 位和第 j 位

然后做两类剪枝：

低位乘法剪枝

两个数乘积的低 d 位 ，只取决于这两个数各自的低 d 位，与高位无关

如果当前已经确定了 p、q 的低 d 位，那么必须满足：

(p_low * q_low) mod 2^d == n mod 2^d

否则这一支直接剪掉。

区间剪枝

当前高低位都部分确定，中间位还没定

于是 p 和 q 都落在一个区间内：

  • p_min <= p <= p_max
  • q_min <= q <= q_max

那么必须满足：p_min * q_min <= n <= p_max * q_max

否则这一支不可能成立，直接剪枝。

固定边界

因为 p、q 都是 512 位素数，所以：

  • 最高位一定是 1（因为是 4 位质数，首位为 1）
  • 最低位一定是 1（质数且大于 2，必为奇数）

Hard_RSA(连分数恢复k,d)

分析

变种rsa：

rsa中有e*d ≡ 1 (mod phi)->e*d ≡ k*phi + 1

所以e / phi ≈ k / d

但我们不知道phi，思考：

  • N^6 非常大，量级大概是 2^6144
  • p^6 + q^6 只有大概 2^3072

可以得到 phi 非常非常接近 N^6

也就是e / N^6 ≈ e / phi ≈ k / d

而我们e和N都已知，可以将e / N^6拿去做连分数逼近来恢复k/d

连分数逼近常用于从一个实数近似值里，找出“最可能的真分数

例如e / N^6是一个超高精度的有理数近似，它非常接近某个真分数k / d

所以把 e/N^6 做连分数展开，就有机会直接把 k,d 找出来。

展开之后如何确定k和d就是我们要找的候选分数呢？:

可以遍历所有收敛分数 k/d，检查是否phi = (e*d - 1) / k

如果是整数，就说明这是一个很强的候选

得到k,d就可以计算出phi了

后续由于p^6 + q^6 = N^6 - phi + 1

可以设S = p + q

得到方程S^6 - 6NS^4 + 9N^2S^2 - 2N^3 = p^6 + q^6

把右边换成已知值。

再令：y = S^2

那么就变成一个三次方程：

y^3 - 6Ny^2 + 9N^2y - (2N^3 + p^6 + q^6) = 0

解出整数根 y 后：S = sqrt(y)

然后就能用：

解二次方程x^2 - Sx + N = 0得到 p,q。
