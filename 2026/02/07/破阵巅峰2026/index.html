看到这个自定义函数：存在严重逻辑漏洞

实现的效果是不是小写字母的全部字符都会被加 32

例如

  • / (ASCII 47) + 32 = O (ASCII 79)

  • . (ASCII 46) + 32 = N (ASCII 78)

我们的目录是读取/flag.txt

不能直接使用 /flag.txt，因为会被转换成 OflagNtxt

需要构造一个字符串，经过 mylowercase() 转换后变成 /flag.txt

/ (47) ← 需要输入 47 - 32 = 15 (\x0f)

. (46) ← 需要输入 46 - 32 = 14(\x0e)

所以直接输入：

在 URL 中使用百分号编码：

- \x0f → %0f

- \x0e → %0e
