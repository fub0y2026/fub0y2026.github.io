FrankenPHP处理CGI请求路径Lower导致字节逃逸

FrankenPHP 是一个比较新的 PHP 应用服务器（Application Server），它把 PHP 直接嵌入到高性能 Web 服务器里运行，而不是像传统方式那样通过 PHP-FPM 或 CGI 方式转发执行。

也就是说：FrankenPHP = 内嵌 PHP 的高性能 Web 服务器

frankenphp/cgi.go at 19d00a08e2217167918aa7c32c056c1a70f22021 · php/frankenphp

FrankenPHP 作为应用服务器，需要处理 CGI 请求，关注frankenphp/cgi.go splitCgiPath函数

主要作用是切分cgi文件路径，得到SCRIPT_NAME, SCRIPT_FILENAME, PATH_INFO, DOCUMENT_URI 这四个参数。

大致流程：

  • 当访问 /something.php/extra 时，它会在路径中找 .php（或其它配置的分割点）
  • 找到后，将 .php 前面部分作为 SCRIPT_NAME（实际脚本路径），后面作为 PATH_INFO
  • 使用 lowerPath 查找，但分割索引基于 原 path 长度来计算（因为 idx 是小写后字符串中的位置）
